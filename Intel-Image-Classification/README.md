# Intel Image Classification Using CNN, MobileNetV2 & Grad-CAM

## Project Overview
This project focuses on image classification using the Intel Image Classification dataset. It explores a custom Convolutional Neural Network (CNN), Transfer Learning using MobileNetV2, and Grad-CAM for visualizing image regions that influence model predictions.

## Dataset
The project uses the [Intel Image Classification dataset](https://www.kaggle.com/datasets/puneet6060/intel-image-classification) from Kaggle.

The dataset contains six categories:
- Buildings
- Forest
- Glacier
- Mountain
- Sea
- Street

## Technologies Used
- Python
- TensorFlow and Keras
- Convolutional Neural Networks (CNN)
- MobileNetV2
- Transfer Learning
- Grad-CAM
- NumPy and Pandas
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

## Project Workflow
- Dataset discovery and preparation
- Image preprocessing and class verification
- CNN model development
- Transfer Learning using MobileNetV2
- Model evaluation and comparison
- Grad-CAM visualizations for model interpretability

## How to Run
1. Open the notebook in Google Colab.
2. Set up access to the Kaggle dataset using the notebook's instructions.
3. Run the cells in order.
4. Train and evaluate the models.
5. Explore the evaluation results and Grad-CAM visualizations.

## Project Files
- `intel_cnn_mobilenet_gradcam_reorganized.ipynb`: The organized notebook containing the project workflow and implementation.
